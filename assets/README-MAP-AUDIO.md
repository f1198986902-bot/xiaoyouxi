## 原创性与合规声明
本资源包内的所有像素图块、建筑贴图、树木物件、行走小人、光标动画以及三首背景音乐（含旋律、和声进行、编曲配器与母带合成）均为专门针对《灰灯镇 / Ashlamp Town》独立创作的 **100% 纯原创资产**：
- **美术部分**：延续已完成的 GBA《火焰之纹章：烈火之剑》时期手绘像素与赛璐璐上色体系（`#1B191E` 深炭褐轮廓线、3~4 阶硬边明暗色阶、灰绿苔石与暖金油灯色调），未临摹、描摹、拼接或改动任何任天堂/火焰之纹章官方地图图块、建筑或地图精灵。
- **音乐部分**：采用 GBA / 16-bit 战术 RPG 室内管弦与木管配器风格独立谱曲，未复刻、改编、插值或模仿任何官方曲目的旋律或和声进行。
- **纯净交付**：仅包含与仓库对应的 `assets/map/`、`assets/audio/` 及说明文档，不含任何修改仓库或代码的脚本。
